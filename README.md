# Интерактивные живые обои (Sci-Fi Interface) для Lively Wallpaper

Интерактивные живые обои для рабочего стола, объединяющие 5 видеопотоков в единый футуристичный интерфейс. Сделано для себя, делюсь со всеми желающими.

### 🛠 Как запустить:
1. Скачайте `.zip` архив проекта со страницы ниже.
2. Откройте программу **Lively Wallpaper**.
3. Перетащите скачанный архив прямо в окно программы или нажмите кнопку **"Добавить обои" (+)** и выберите этот файл.
